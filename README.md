# codeshot

Turns code into a shareable PNG with syntax highlighting. Paste or open a file, then save the image or copy it to the clipboard.

    codeshot [file]

| Key | Action |
| --- | --- |
| Esc / Ctrl+L | Leave / focus the editor |
| Space, Ctrl+Shift+C | Copy image |
| Ctrl+S | Save PNG to ~/Pictures |
| L | Next language |
| W | Toggle window frame |
| ? | Shortcuts |
| Q, Ctrl+Q | Quit |

Build with `bin/build`, test with `bin/test`, install with `bin/install`.
